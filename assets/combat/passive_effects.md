# K 패시브 연출

`passive_effects.aseprite`는 128×128 캔버스, 14태그×8프레임 원본이며 PNG는 1024×1792다. 가로 시간8칸, 세로 PassiveEffectDB.EFFECTS의 row 순서다. 원본은 Aseprite Lua로 제작했다.

습득 / 강화 타격 / 회오리 / 관통·다중 사격 / 불씨 폭발 / 회복 / 방어 문양 / 바람 궤적 / 채집 / 보물 / 건설 / 요새화 / 가시 / 복귀를 구분한다. 각 연출은 투명 배경·얇은 궤적 위주이며, 반경 기준48px를 실제 표시 반경으로 조절한다. 시간은 PassiveEffectDB의 연출용 값이며 판정 지속시간이 아니다.

K 패시브55종은 PassiveEffectDB.NODES에 모두 분류되어 있다. 모든 노드는 배우기 성공 시 습득 파동을 표시한다. 실제 조건이 있는 노드는 해당 성공 지점에서 발동 그림을 표시하고, 상시 능력치 노드는 습득 표시와 기존 UI 수치/공격 동작으로 표현한다. 장비 액티브를 새로 제작한 작업은 아니다.

캐릭터별 연출은 같은 계열0.6초 간격, 화면 효과 수48개 기준 제한으로 겹침을 줄인다. 원격 캐릭터는 ID·위치·범위만 받아 그림을 재생한다. 월드 결과 효과는 호스트가 공유한다. 피해·드롭·회복·판정용 난수에는 영향이 없다.
