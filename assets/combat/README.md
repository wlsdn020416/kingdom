# 무기·공격 그래픽

기존 캐릭터·낡은 검의 남색 테두리·강철·가죽·황동 색에 맞춘 픽셀아트다. 무기와 투사체·효과 모두 같은 이름의 Aseprite 원본과 투명 PNG를 보관한다.

| 원본 / PNG | 규격 | 배치 |
| --- | --- | --- |
| `weapons` | 512×384, 64×64 칸 | 8열×6행. 0열 대기, 1~7열 공격·회복. 낡은 검·흑요석 검·낡은 활·산탄 석궁·화염 지팡이·폭탄 주머니 순서 |
| `projectiles` | 128×192, 32×32 칸 | 4열×6행. 화살·볼트·작은 화염탄·화염구·폭탄·적 마법탄 |
| `attack_effects` | 768×640, 128×128 칸 | 6열×5행. 강철 검 궤적·흑요석 검 궤적·명중·폭발·화염 명중 |

원본 태그는 아이템/효과 ID다. 무기 원본은 `무기·재질`과 `장갑·팔` 두 레이어로 편집할 수 있다. 원본은 태그 순서대로 타임라인에 있고, PNG는 태그 하나를 한 행으로 펼친 시트다. 내보낼 때 투명 여백을 자르거나 칸을 합치지 않는다. 무기 피벗은 칸 안 `(20, 32)`이다.

게임에서의 배치·시간은 `data/weapon_art.gd`의 `WeaponArtDB`를 따른다. 무기는 대기 뒤 7프레임을 0.18~0.28초 동안 재생하며 몸에 짧은 반동을 준다. 두 검의 타격 궤적은 0.12초이고 기존 즉시 판정에 맞춰 첫 칸부터 전체 부채꼴을 표시한다. 휩쓸기 패시브의 각도 확장은 칼끝 사거리를 유지하며 궤적 양 끝을 넓혀 표시한다. 활은 시위 복귀·재장전, 석궁은 반동·섬광, 지팡이는 시전, 폭탄은 투척 자세다. 장비창 아이콘은 같은 대기 칸에서 48×48 영역을 재사용한다.

투사체 그림과 폭탄의 떠오름·회전은 연출만 바꾼다. 기존 피해·속도·수명·사거리·폭발 반경은 유지한다. 원격 플레이어도 `WeaponVisual`을 사용하며 표시 전용 탄(`visual_only`)은 게임 상태를 바꾸지 않는다. 명중·폭발은 호스트가 확정한 뒤 공유한다.

`rusty_sword.aseprite`·PNG와 `sword_slash.aseprite`·PNG는 최초 제작 원본으로 보존했다. 실제 게임은 위 공용 시트를 사용한다. 무기 모션·투사체·효과·장비창은 Godot 렌더링으로 확인했고 자동 검사는 `sh tests/run_all.sh`에 포함한다. 연속 공격의 손맛·밤 가독성은 사용자가 `godot --path .`로 직접 확인 필요.

## 무기 트리 34종 적용

현재 손에 드는 무기·장비 아이콘은 `weapon_tree.aseprite`/PNG(512×2176, 64×64·8열×34행)를 사용한다. 정확한 ID·행·계열·강화 단계는 `data/weapon_art.gd`의 WEAPONS를 따른다. 대검의 두꺼운 칼날·무게감, 쌍검의 두 칼과 겹친 잔상, 수호검의 방패/왕실 문양, 장궁과 짧은 연사궁, 다중 총열 산탄과 기계식 공성 석궁, 화염/얼음 결정/번개 갈고리 지팡이로 구분했다. 상위 단계는 재질·보석·장식·발광을 추가한다.

`weapon_tree_projectiles`는 128×800(32×32·4열×25종), `weapon_tree_effects`는 768×3200(128×128·6열×25종)이다. 각각 TREE_PROJECTILE_ROWS, EFFECTS의 tree 항목 순서다. 기본 탄·폭탄·최초 검 궤적·기존 명중은 원래 시트를 함께 사용한다. 폭탄 주머니도 원래 무기 시트에 남는다. 무기 트리 아이콘은 대기 프레임의 (4,4)부터 56×56을 쓴다.

`tools/build_weapon_tree_art.lua`를 Aseprite batch Lua로 실행하면 시트·원본·태그를 재생성한다. 스킬 8종 아이콘은 `assets/ui/weapon_skill_icons`(32×256)에 출력한다. 투사체 종류와 스킬 그림은 실제 공격 경로에 연결하며 연쇄 번개 연결선·공성 폭발·강화 화염구도 구분한다. 연출은 피해·쿨타임·수용량·게임 결과용 난수를 바꾸지 않는다. 원격 그림은 PlayerSync/CombatSync가 공유한다.

손에 드는 표시 크기 조정: WeaponVisual.HELD_SCALE=0.5로 무기 34종·폭탄 주머니의 대기/공격 그림을 손잡이 피벗 기준 절반으로 그린다. 원본 PNG/Aseprite, 아이콘 크롭, 투사체·공격 궤적·피해 사거리는 그대로다. 로컬/원격 플레이어 공통이다.

## 장착 연결 보정 (2026-10-26)

무기 트리 34종의 손·소매를 2px 단위 색 덩어리로 다듬어 절반 크기에서도 손잡이 연결이 남게 했다. WeaponVisual은 손 그림의 기준을 몸통 부근 `(0,-3)`에서 조준 방향으로 4px 이동하고, 왼쪽을 조준하면 무기만 로컬 Y축으로 반사해 활·석궁이 뒤집히지 않는다. 크기와 전면 표시, 검 궤적의 기준·판정은 유지한다.
