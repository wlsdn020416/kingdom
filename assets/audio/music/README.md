# 왕국의 황혼 — 시작 화면 BGM

보컬 없는 잔잔한 중세 판타지 연주곡. 류트·하프·플루트·현악기·부드러운 호른과 절제된 프레임 드럼을 요청했다. ElevenLabs Music v2.5의 기본 4개 변형을 한 번 생성했으며, 재생 음량 변화가 가장 작았던 01을 메뉴용으로 선택했다. 청음에 의한 최종 음악성·음량 평가는 사용자 확인이 필요하다.

- `title_theme.ogg`: 게임용 48kHz 스테레오 Vorbis, 약 74.29초. 앞뒤 1.5초를 크로스페이드해 반복 경계를 연결했다. 디코딩 후 피크 약 -3.04dBFS, RMS 약 -20.04dBFS, 경계 샘플 차이 0.00389 미만.
- `sources/title_theme_01.mp3`~`04.mp3`: 90초 생성 원본. `.gdignore`로 중복 임포트를 막는다.
- `manifest.json`: 프롬프트·모델·생성 ID·선택 근거. 임시 다운로드 URL은 저장하지 않는다.
- `mix.json`: 편집 구간·측정값·SHA-256. 요청한 76 BPM 기준 길이이며 실제 박자 검출·화성 분석 결과가 아니다.
- `tools/build_menu_music.py`: 재현용 편집 도구(Python + numpy + soundfile). 런타임 설치는 필요 없다.

Title이 AudioStreamPlayer와 복제된 loop 스트림을 소유한다. -60dB에서 `SoundDB.TITLE_MUSIC_VOLUME_DB`(-8dB)까지 1.6초 페이드인한다. 싱글/멀티 팝업에서는 같은 음악이 이어지고, 게임 진입·타이틀 종료 시 재생기가 해제된다. `--seed` 즉시 시작 경로에서는 메뉴 음악을 만들지 않는다. 효과음의 음량·동작은 유지한다. 게임 안 보스전 음악은 아래 별도 항목을 따른다.

출처: ElevenLabs 음악 생성. 사용 계정의 배포·상업 이용 조건은 기존 효과음과 동일하게 계정 플랜을 기준으로 관리한다.

# 왕국의 결전 — 보스전 BGM

ElevenLabs Music v2.5로 생성한 보컬 없는 중세 판타지 전투 연주곡. 요청한 방향은 136 BPM·D minor, 빠른 저음 현악 리듬, 4음 호른/저음 금관 동기, 팀파니·프레임 드럼, 해머드 덜시머다. 박자·조성은 생성 프롬프트이며 실제 검출 결과가 아니다.

- `boss_theme.ogg`: 게임용 48kHz 스테레오 Vorbis, 약 98.82초. 약 1.76초 크로스페이드 반복. 디코딩 후 피크 -3.58dBFS, RMS -18.09dBFS, 경계 샘플 차이 0.01173 미만.
- `sources/boss_theme_01.mp3`~`04.mp3`: 기본 변형 4개, 각 120초. 기존 `.gdignore`로 게임 임포트에서 제외한다.
- `boss_manifest.json`: 생성 모델·프롬프트·생성 ID. 임시 다운로드 URL은 저장하지 않는다.
- `boss_mix.json`: 선택 원본(04)·편집 구간·음량·경계 측정값·해시.
- `tools/build_boss_music.py`: Python + numpy + soundfile. 원본 4개의 132개 구간 중 지속 에너지의 변화와 접합부 에너지 차이를 비교해 선택한다. 음악성이나 화성 연결을 평가한 결과는 아니므로 최종 청음 확인이 필요하다. 긴 Vorbis 단일 쓰기의 libsndfile 네이티브 오류를 피하려고 4096프레임씩 기록한다.

Main의 `BossMusic`(`MusicPlayer`)가 복제된 loop 스트림을 소유한다. 보스 등장 시 -60dB에서 `SoundDB.BOSS_MUSIC_VOLUME_DB`(-7dB)까지 1.2초 페이드인한다. 호스트 Enemy와 참가자 EnemyPuppet을 기존 `boss_status()`로 읽는다. 밤이 끝나도 살아 있는 보스가 있으면 계속 재생한다. 마지막 보스 제거·승리·멸망 시 1.2초 페이드아웃 후 정지한다. 전략회의는 재생 위치를 보존한 채 멈추고, 재개 시 이어 듣는다. 씬 종료 시 재생기가 해제된다. 각 보스에 공통 곡 하나를 사용하며 효과음 파일/음량은 유지한다.

출처·이용 조건은 위 메뉴 BGM과 같은 ElevenLabs 생성 계정 기준이다. 사용자가 보스전에서 효과음 대비 음량·반복 연결·분위기를 직접 청음해야 한다.
