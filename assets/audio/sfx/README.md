# 기본 효과음 제작 초안

2026-10-26 제작. 현재 구현된 행동에 쓰는 **43종·168개 변형**이며 게임 재생에 연결했다. 최종 청음과 체감 음량 확인이 필요하다.

`index.html`을 브라우저에서 열면 분류·검색·변형 선택·음량 조절·미리듣기·WAV 저장을 할 수 있다. 게임을 실행할 필요가 없고 인터넷 연결도 필요 없다. 미리듣기 페이지는 한 번에 한 소리만 재생한다.

## 파일 구성

- `movement/`, `combat/`, `skills/`, `world/`, `kingdom/`, `ui/`, `alerts/`: 게임용 WAV. 이름은 `<용도>_<변형 번호>.wav`.
- `sources/`: ElevenLabs가 생성한 MP3 원본. `.gdignore`로 Godot의 중복 임포트를 막는다.
- `manifest.json`: 전체 용도·프롬프트·생성 ID·원본 경로·편집 내역·길이·피크·SHA-256.
- `index.html`: 로컬 미리듣기. 파일을 고른 뒤 재생 버튼을 누른다.

게임용 파일은 **44.1kHz·16bit·모노 PCM WAV**, 반복 없음이다. 5ms RMS 창으로 첫 어택을 찾아 앞 10ms를 남기고, 앞뒤 무음과 긴 반복 구간을 정리했다. 긴 생성물은 용도별 최대 길이로 첫 소리를 발췌했다. 시작 1ms·끝 15ms 페이드, DC 오프셋 제거, 종류별 피크 조정(이동 -9dBFS, UI -10dBFS, 알림 -3dBFS, 그 외 -4dBFS, 최대 증폭 24dB)을 적용했다. 이는 피크 정리이며 체감 음량을 맞춘 최종 믹싱이나 청음 검수를 의미하지 않는다. 전체 길이 원본은 보존했다.

## 포함한 소리

| 분류 | 종류 수 | 용도 |
| --- | ---: | --- |
| 이동 | 4 | 풀밭·돌바닥·얕은 물 발걸음, 대시 |
| 전투 | 9 | 검, 활, 석궁, 마법탄, 적·갑옷 타격, 플레이어 피격·쓰러짐, 적 처치 |
| 스킬 | 6 | 산탄, 화염구, 폭탄·폭발, 보호막, 치유, 함성·전쟁 뿔피리 |
| 채집·상자 | 6 | 나무·바위 타격, 나무·바위 파괴, 자원 획득, 상자 열기 |
| 건설·왕국 | 8 | 설치, 수리, 철거·파괴, 제작, 업그레이드, 입고, 핵 피격, 멸망 |
| 인터페이스 | 7 | 클릭, 창 열기·닫기, 불가 알림, 장착, 레벨 상승·패시브 습득, 지도 핑 |
| 시간·침공 | 3 | 낮 시작, 밤·침공 시작, 보스 등장 |

대부분 4개 변형이다. 생성 큐 제한으로 폭발은 3개, 나무 파괴는 1개이며, 생성이 시작된 항목을 추가로 생성하지 않았다. 몬스터별 전용 울음, 음악, 환경음 루프는 포함하지 않았다. 물 발걸음은 늪, 돌 발걸음은 왕국·화산에서 사용한다.

## 게임 연결

`data/sounds.gd`에서 파일·음량·재생 간격을 조정한다. `SoundEffects`는 Main에서 청취 플레이어와 카탈로그를 주입받으며 변형을 순환 재생한다. 이동·공격·피격·스킬·채집·건설·제작·UI·침공 알림에 연결했다. 폭탄은 실제 폭발 때 울리고, 건설·제작 성공음은 성공한 명령에서만 울린다. 호스트가 월드 결과음을 공유하며 내 캐릭터의 소리는 즉시 재생하고 반송하지 않는다. 위치음은 거리 감쇠와 좌우 배치를 적용하고, UI·시간 알림·멸망음은 일시정지 중에도 재생한다.

## 출처와 남은 확인

ElevenLabs Sound Effects v2로 제작했다. [원본 제작 Flow](https://elevenlabs.io/app/flows/ANUzuoGIetPrkRAwWzpo)와 `manifest.json`의 생성 ID로 추적한다. 이용 권한은 생성 계정의 ElevenLabs 플랜·약관을 따른다.

WAV 디코딩·파일 형식·무음·클리핑·해시·Godot 리소스 로딩을 검사했다. 게임 재생 경로·실제 믹서 출력·동시 재생 제한·거리 제외·일시정지·2인 전달은 `sh tests/run_all.sh`에서 확인한다. 실제 소리의 어울림·반복 피로도·스킬 구분은 `index.html`에서, 동시 재생과 체감 음량은 사용자가 `godot --path .`로 직접 확인 필요.
