# 건물 그래픽

`buildings_expanded.aseprite`는 64×96 캔버스, 접지 그림자·구조/장치의 2개 레이어, 23개 태그×4프레임이다. PNG는 1472×384, 가로 외형 23칸·세로 시간 4칸이며 프레임은 0.16초다.

순서: 나무벽·돌벽·가시 목책·단단한 목벽·철벽·흑요석 성벽·정수 방벽 / 화살탑·발리스타·대포탑·서리탑·화염탑·번개탑 / 장비 상자·제작대0·1·2·3 / 순간이동 탑·모닥불·보급소·감시탑 / 나무 문(22번 칸, 나중에 추가해서 맨 뒤). BuildingDB의 sprite_column이 이 순서를 가리킨다. 제작대의 sprite_tops는 단계별 체력바 높이다.

64px 폭은 큰 장치/투사 외형을 위한 투명 여백을 포함한다. 월드 위치 (-32,-80), 기존 32×32 충돌을 유지한다. 메뉴·도감·미리보기·멀티플레이는 같은 그림을 사용한다. 기존 buildings.aseprite/PNG는 최초 8칸 시안으로 보존했다. 새 원본은 Aseprite Lua로 제작했다.

월드 표시 크기 조정: 공성탑 6종은 70%, 생활 건물(장비 상자·제작대·순간이동 탑·모닥불·보급소·감시탑)은 55%로 그린다. 벽·문·성의 크기는 유지한다. Building.draw_art가 위치와 크기를 같은 비율로 줄이며 설치 미리보기/도감 상세·체력바 높이에도 반영한다. 원본 크롭 아이콘·설치 칸·충돌 크기는 바꾸지 않는다. 건물 야간 빛은 반경 65%·밝기 30%, 성은 210px·35%로 완화했고 플레이어 빛은 유지한다.

## 구조·재질 보정 (2026-10-26)

`tools/polish_pixel_art.lua`로 기존 원본의 보정 레이어를 교체한다. 제작대 4단계의 상판·다리 사이 투명 틈을 연결하고 장부·가로 버팀목·발 고정쇠를 추가했다. 발리스타 중심 축, 대포 받침, 상자 뚜껑 접합선과 건물 우측 면·기단 명암을 보강했다. 23종×4프레임 및 크기·접지점은 유지한다.
