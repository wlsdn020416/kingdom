# 건물 그래픽

`buildings_expanded.aseprite`는 64×96 캔버스, 접지 그림자·구조/장치의 2개 레이어, 22개 태그×4프레임이다. PNG는 1408×384, 가로 외형 22칸·세로 시간 4칸이며 프레임은 0.16초다.

순서: 나무벽·돌벽·가시 목책·단단한 목벽·철벽·흑요석 성벽·정수 방벽 / 화살탑·발리스타·대포탑·서리탑·화염탑·번개탑 / 장비 상자·제작대0·1·2·3 / 순간이동 탑·모닥불·보급소·감시탑. BuildingDB의 sprite_column이 이 순서를 가리킨다. 제작대의 sprite_tops는 단계별 체력바 높이다.

64px 폭은 큰 장치/투사 외형을 위한 투명 여백을 포함한다. 월드 위치 (-32,-80), 기존 32×32 충돌을 유지한다. 메뉴·도감·미리보기·멀티플레이는 같은 그림을 사용한다. 기존 buildings.aseprite/PNG는 최초 8칸 시안으로 보존했다. 새 원본은 Aseprite Lua로 제작했다.
