# 일반 적과 보스 픽셀 그래픽

일반 적은 기존 `enemies.aseprite`·`enemies.png`(256×512, 64×64 4프레임)를 사용한다. 0~6행은 일반 적 7종이며 마지막 7행의 최초 공통 보스 그림은 원본 기록으로 보존한다.

보스는 별도 `bosses.aseprite`·`bosses.png`를 사용한다. 128×128, 8프레임×7행의 1024×896 아틀라스다. Aseprite 원본은 56프레임·ID별 태그이며 접지 그림자 / 몸체·장갑·장식 / 눈·핵·문양 레이어를 분리했다. `bosses_layout.json`은 행·모든 프레임의 최상단 좌표다. 런타임은 `EnemyDB.sprite_row`·`sprite_top`을 읽는다.

| 일차 | 보스 | 외형 컨셉 | 기존 전투와의 연결 |
| --- | --- | --- | --- |
| 3 | 타락한 수호자 | 찢긴 망토·부서진 원광, 탑 방패와 보랏빛 오염 핵이 드러난 폐허 기사 | 원형탄·슬라임 소환 |
| 6 | 늑대 군주 | 은회색 거대 늑대, 뼈 왕관·찢긴 붉은 천·긴 송곳니 | 빠른 돌진·늑대 무리 |
| 9 | 독침 폭군 | 황동빛 갑각, 비대칭 집게·초록 독낭·몸 위로 치켜든 분절 꼬리 | 회전 연사·부채꼴 독침 |
| 12 | 서리 거신 | 빙하 어깨와 얼음 수염, 균열 난 석재·차가운 룬 핵 | 느린 방사탄·무거운 돌진 |
| 15 | 늪의 어머니 | 버섯이 자란 등, 알집이 보이는 배·이끼·뿌리 다리 | 늪 슬라임 증식·나선탄 |
| 18 | 화염 군주 | 용암으로 연결된 흑요석 판갑·뿔·불꽃 관과 떠 있는 하체 | 빠른 화염 연사·돌진 |
| 21 | 왕국 파괴자 | 어깨 망루·성문 용광로·거대한 철권, 부서진 왕관을 쓴 걸어오는 성채 | 모든 패턴을 쓰는 최종 공성 괴수 |

보스마다 8프레임의 호흡·다리/집게 움직임·꼬리·불꽃·포자 변화를 만들었다. Enemy는 보스만 8칸을 순환하고 일반 적은 기존 4칸을 유지한다. 기존 분노 체력 조건에서는 호흡 속도와 밝기를 조금 높이며 피격·돌진 예고의 번쩍임을 유지한다. EnemyPuppet도 동일한 그리기와 호스트 프레임을 사용한다.

그림의 원점은 (-64,-104)이고 접지 그림자는 y=109 부근이다. 앞뒤 순서는 기존 월드 배치 기준점으로 정한다. 체력바는 보스별 모든 프레임의 최상단 위에 놓는다. 뿔·집게·화염은 외형 장식이며 충돌 반경·피해·패턴·보상 수치를 확대하지 않는다.

재현: 저장소 루트에서 Aseprite batch로 `tools/build_boss_art.lua`를 실행한다. PNG와 원본·배치 JSON을 함께 만든다. 게임 런타임은 GDScript만 사용한다.
