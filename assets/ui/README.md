# 메뉴·패시브 그래픽

모든 시트는 PNG와 편집 가능한 Aseprite 원본을 함께 제공한다. 픽셀 아이콘·프레임은 Aseprite Lua로 제작했다.

| 파일 | 구성 |
| --- | --- |
| passive_icons | 32×32, 가로 8칸, 총 55개 아이콘. 순서는 data/passive_art.gd의 ICON_ORDER. Aseprite는 ID별 단일 프레임 태그 |
| passive_nodes | 56×56, locked·available·learned·selected·complete 5상태 |
| menu_chrome | 384×192 아틀라스. 패널·버튼 기본/호버/누름/포커스·중앙 왕관·싱글/멀티 아이콘. 영역은 MenuArt 상수 |

시작 배경: `assets/branding/title_background.png` 및 `.aseprite`(원본 그림 한 레이어). 내장 image_gen으로 생성했으며 로고와 문자는 별도로 합성한다.

배경 제작 프롬프트: 중세 협동 생존 왕국 디펜스 게임 KINGDOM SYSTEM의 16:9 타이틀 배경. 정교한 픽셀아트, 어두운 남색 전나무 숲과 산악 계곡, 황혼의 금빛 수평선, 오른쪽에 횃불이 켜진 돌 성과 남색 금색 깃발, 계곡의 강과 다리, 성으로 이어지는 길. 왼쪽 40%는 로고와 메뉴를 위한 어둡고 여백이 있는 숲과 안개. 아름다운 원근감, 제한된 남색·청록·호박색 팔레트, 하드 픽셀 가장자리, 게임 화면 같은 통일된 디테일. 텍스트·로고·버튼·UI·사람·워터마크 없이 불투명 배경.

## 건설·전체 장비 그래픽

- `equipment_items.aseprite`·PNG: 48×48, 5열×3행, ItemArtDB.ORDER의 장비 15종. 기존 무기 5종·폭탄은 같은 무기 원본 픽셀을 재사용하고 나머지 9종은 고유 아이콘을 추가했다.
- `construction_materials.aseprite`·PNG: 24×24 3칸, 석탄·송진·보스 정수. 앞의 재료 12종은 기존 material_icons를 그대로 쓴다.
- B 건설 도감은 MenuArt의 패널/버튼과 실제 건물 아틀라스로 카드·상세·설계 격자를 구성한다. 잠긴 건물도 외형을 확인할 수 있고 실제 설치는 기존 명령 경로다.
- 착용 원본은 assets/characters/equipment_worn.aseprite, 건물 원본은 assets/kingdom/buildings_expanded.aseprite.


## 게임 화면 레벨·경험치

`progression_hud.aseprite`·PNG는 128×64 아틀라스다. 일반 왕관 레벨 배지 (0,0,48,56), 레벨업 강조 배지 (48,0,48,56), 경험치바 테두리 (96,0,32,12), 보라색 채움 (96,16,26,6)을 담는다. 숫자·경험치·포인트는 실제 Progression 값으로 별도 그려 글자가 그림에 고정되지 않는다. Aseprite Lua로 직접 제작했으며 nearest 필터로 표시한다.

상단 왼쪽 상태창의 252×44 ProgressionHud에서 레벨 배지, 현재/필요 경험치와 진행바, K 패시브 포인트 버튼을 표시한다. 획득 시 0.3초 보간, 레벨업 시 1.4초 강조이며 감소는 즉시 반영한다. 사망·다중 레벨업·포인트 소비는 기존 규칙을 따른다.


## 왕국 집무실

`kingdom_ui.aseprite`·PNG는 256×64 아틀라스다. 48×48 네 칸은 제작대 강화(모루·망치·결정), 방어 강화(성벽 방패), 영토 확장(나침반·바깥 표식), 수리(석재·도구)이고 (192,0)의 64×64는 왕관 문장이다. 기존 성채 원본과 함께 핵 옆 E의 KingdomPanel에 사용한다. 네 카드에 보유/필요 재료와 실행 조건을 표시하고 툴팁으로 가방·창고 수량을 구분한다. 1280×720·960×600에 맞춰 패널 전체를 조정한다.

제작대 창은 강화 UI를 제거하고 장비 목록/제작 상세 두 열만 표시한다. 제작대 단계는 상단에 남기며 강화는 왕국 핵 집무실에서 한다.

## 미니맵·재료 가방

`minimap_ui.aseprite`/PNG는 256×128이다. (0,0,96,112) 지도 프레임, (96/144/192,0,48,64) 가죽 가방 일반/주의/만원, (96+16×index,72,16,16) 성·플레이어·침공·탑·핑·북쪽 표식 순서다. 가방 포켓의 적재 게이지는 실제 칸 비율로 그린다. Hud에서는 96×84로 가방 높이를 축소하고 그림 오른쪽에 칸 수·퍼센트를 표시한다. 미니맵은 192×224, 가방은 좌측 10px 간격이다. 재현: `tools/build_minimap_art.lua`.

`weapon_skill_icons.aseprite`/PNG(32×256)는 내려찍기·돌진 베기·반격·저격·화살비·폭발 볼트·서리 고리·낙뢰 순서의 32×32 고유 아이콘이다. 기존 슬롯 상태 프레임은 skill_ui를 계속 사용한다.

## 화면별 커서

`cursor_menu`·`cursor_hand`·`cursor_aim`은 각각 32×32의 PNG와 Aseprite다. 메뉴는 황동 테두리·강철 화살촉·청록 보석, 버튼은 왕실 장갑, 게임은 밝은 중심점·십자 눈금·청록 모서리의 조준점이다. 남색 외곽선을 사용해 밝은 땅에서도 구분한다. 클릭 기준점은 메뉴 (3,2), 손가락 (10,5), 조준 (16,16)이다. 원본의 투명 여백을 자르지 않는다. `tools/build_cursor_art.lua`를 Aseprite batch Lua로 실행해 재생성한다. Title/Main의 CursorArt.apply와 UiKit 버튼 포인터에 연결한다.

## 환경 설정 창

`settings_ui.aseprite`/PNG(224×64)는 설정 창(D-030) 전용이다. 위 줄은 32×32 섹션 아이콘 4개(소리 스피커·화면 모니터·연출 반짝임·설정 톱니), 아래 줄은 슬라이더 홈(64×12, 0,32)·채움(64×12, 64,32)·손잡이 보통/밝음(16×20, 128,32·144,32)·체크박스 꺼짐/켜짐(24×24, 160,32·184,32)이다. 팔레트는 kingdom_ui와 같다(외곽선 101d29, 청회색 304653·7b929e·c1d1ca, 금색 bf9560·d4ae69·f3d89b). 판·버튼은 menu_chrome을 그대로 쓴다. `SettingsPanel`이 영역을 상수로 가진다.

## 전체 지도·전략회의 창

`map_ui.aseprite`/PNG(96×32)는 32×32 제목 아이콘 3개다: 접힌 지도(전체 지도 M), 왕관 깃발(전략회의 T), 모래시계(회의 현황). 팔레트는 settings_ui·kingdom_ui와 같다. 두 창은 menu_chrome 판 위에 어두운 안쪽 판으로 지도 액자를 두고, 범례는 minimap_ui의 지도 표식(핵·나·침공 적·순간이동 탑·핑)을 그대로 쓴다.

## 장비 아이콘 재질 보정 (2026-10-26)

`tools/polish_pixel_art.lua`로 equipment_items의 비무기 아이콘에 우측 재질 음영, 나무 방패 판재·리벳, 가죽 모자 봉제선을 추가했다. 천 신발은 착용 시트와 같은 천·가죽 색을 쓴다. 무기 아이콘은 개선된 weapon_tree의 손·소매와 같은 원본이다.
