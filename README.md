# KINGDOM SYSTEM

2~4명이 함께 왕국을 지키는 탑다운 2D 픽셀아트 생존 게임입니다.

낮에는 시드로 만들어진 넓은 월드를 탐험하며 자원을 모으고 왕국을 건설하세요. 밤이 오면 몰려드는 몬스터와 보스의 침공을 막아내야 합니다.

장비에 깃든 스킬과 동료와의 협력으로 최종 보스를 쓰러뜨리세요. 왕국이 무너지면 모든 것이 처음부터 다시 시작됩니다.
