## M1 — 2인 접속과 이동 동기화 (다음 목표)

최소 플레이 가능 기준: 두 사람이 같은 월드에서 서로 움직이는 모습을 보며 1인용과 같은 루프를 플레이할 수 있다.

- 완료: Steam 연동 기반(GodotSteam, 테스트 App ID 480, 시작 화면에 Steam 상태 표시, D-016)
- 완료(1단계, D-017): 시작 화면 멀티플레이 칸(Steam 방 만들기·친구 초대·초대 수락 참가, 개발용 IP 열기·참가), 호스트가 시드 전달, 상대 캐릭터 표시와 위치·조준·애니메이션 동기화, 자동 접속 테스트(NET TEST)
- 완료(2단계, D-017): 적·웨이브·낮/밤·왕국 핵·멸망을 호스트만 계산하고 결과 전달, 적이 모든 플레이어를 노림, 참가자의 공격을 호스트의 적에게 다시 실행, 막타 보상, 호스트가 나가면 시작 화면으로
- 남음(M2로): 월드 변경(채집·상자·건물·창고·장비 상자·제작대) 동기화, 도중 참가·재접속
- 같은 시드로 각자 월드 생성 (시드는 호스트가 전달)
- 플레이어 위치·조준 동기화. 적·웨이브·낮/밤·자원은 호스트에서만 시뮬레이션하고 결과를 전달
- 클라이언트의 공격·스킬·건설은 호스트에 요청 → 호스트가 기존 명령 메서드로 처리
- 결정 기록: 동기화 방식, 오토로드 필요 여부(D-002), 연결 끊김 시 최소 처리
- 검증: 한 기기에서 headless 호스트 + 클라이언트 2개 인스턴스를 띄우는 자동 접속 테스트 (완료: `tests/net_test.tscn`)
